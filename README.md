## `~/projects`

**🚗 [OBD-Analyzer](https://github.com/Jozkah/OBD-Analyzer)** · [`datalog.help`](https://datalog.help)
Drop in a CSV from any OBD-II scanner app and see the drive — charts, a pan/zoom GPS
track map coloured by speed, gear estimation, and automatic 0–100 / ¼-mile detection.
Fully client-side; nothing leaves the browser.
<sub>`TypeScript` · `Next.js 14` · `React 18` · `Canvas` · `PWA` · `MIT`</sub>

**⚡ [solar-tesla-charger](https://github.com/Jozkah/solar-tesla-charger)**
Reads Shelly EM meters, a Tesla Wall Connector and SolaX/Growatt inverters in real time,
then tunes the car's charging amperage to track solar export surplus. Live dashboard,
SQLite history, scheduled overnight grid charging.
<sub>`Node.js` · `Express` · `SQLite` · `Tesla Fleet API` · `SSE`</sub>

**🖨️ [3d-print-calculator](https://github.com/Jozkah/3d-print-calculator)**
Filament, time and cost estimation for print jobs.

## `~/off-screen`

Not everything I do ends up in a repo. The hands-on work feeds the software —
most of the tools above exist because I needed them for one of these.

<table>
<tr>
<td width="50%" valign="top">

### 🖨️ 3D printing

Running FDM machines as an actual service rather than a hobby: material selection,
tuning profiles for parts that have to fit something real, failure diagnosis, and
quoting jobs properly instead of guessing. This is where the print calculator came from.

<sub>`FDM` `slicer toolchains` `CAD/mesh repair` `cost modelling`</sub>

</td>
<td width="50%" valign="top">

### 🚁 Aerial photogrammetry

Drone survey capture and turning the imagery into usable geometry — flight planning
for overlap, ground control, mesh and orthomosaic reconstruction, and cleaning the
output into something a client can actually measure against.

<sub>`flight planning` `photogrammetry` `mesh reconstruction` `orthomosaics`</sub>

</td>
</tr>
<tr>
<td width="50%" valign="top">

### ☀️ Solar installation

Designed and installed my own PV system after installer quotes came back unserious.
String sizing against MPPT voltage windows, grid-code compliance, export limiting,
and chasing down the derating behaviour that makes an inverter quietly under-deliver.

<sub>`PV string design` `EN 50549-1` `inverter config` `battery sizing`</sub>

</td>
<td width="50%" valign="top">

### 🔧 Vehicle work

A track-oriented build maintained hands-on — brakes, suspension geometry, alignment,
and datalogging every session to see whether a change actually did anything. The OBD
analyzer exists because reading those logs by hand was miserable.

<sub>`OBD-II datalogging` `brake & suspension` `alignment` `engine data`</sub>

</td>
